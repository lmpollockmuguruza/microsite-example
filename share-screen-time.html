    What happens to the screenshot (not built in this mock-up):

    • It's saved under the family ID the parent signed in with, so they never have to type an ID.
    • It's stored on UK-hosted storage, and the location data and other metadata in the image file are removed when it's uploaded.
    • A separate process reads the numbers from it (Gemini API on PUBLIC's paid terms, or open-source OCR), and a sample is checked by hand.
    • The image is deleted after [TBC] months. Only the numbers are kept.
