Accessibility statement

We want as many people as possible to be able to use this website. For example, you should be able to:

  • zoom in up to 400% without the text spilling off the screen
  • navigate the whole website using just a keyboard or speech recognition software
  • listen to the website using a screen reader
  • watch every video with subtitles, or read a transcript
